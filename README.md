# Alien_Invasion is a game I am building to learn more in python:
### It is a game that tells us how US soldiers will defend the US when aliens invade the planet known as earth
# Steps in building game invasion:
## STEP 1: 
- create venv in your cloned remote repo:
```
python -m venv .venv
```
Note: second (.venv) is the name of the venv folder
- use pip to install pygame-ce
```
pip install pygame-ce
```
- create a main python folder and file named src or lib then main.py
- import sys and pygame in main.py
```
import sys
import pygame
```
